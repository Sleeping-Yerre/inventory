# MangaLens Android 0.1.2 사용 안내

## 휴대폰에 설치

1. 휴대폰 브라우저에서 [APK 받기](https://github.com/Sleeping-Yerre/inventory/raw/refs/heads/main/downloads/MangaLens-Android.apk)를 누릅니다.
2. 받은 `MangaLens-Android.apk`를 열어 설치합니다. Android가 설치 출처 허용을 요청하면 화면 안내에 따라 직접 확인합니다.
3. MangaLens를 열고 **Continue with ChatGPT**를 누릅니다.
4. 휴대폰의 브라우저에서 본인 계정으로 로그인하고 **ChatGPT 요금제 사용**을 허용합니다. 비밀번호나 브라우저 쿠키를 앱이 읽지 않습니다.
5. 연결 완료 페이지에서 앱으로 돌아옵니다. 모델 목록이 나오지 않으면 **모델 새로고침**을 누릅니다.
6. **번역 모델**과 **추론 수준**을 고릅니다. 지원하는 추론 수준만 표시합니다. 선택은 자동으로 저장합니다.

휴대폰에서는 별도로 로그인합니다. PC에 저장한 로그인 정보를 APK에 넣거나 휴대폰에 복사하지 않습니다. 일반 유료 API로 전환하는 기능은 없습니다.

## 그림 위에서 번역

1. **작은 번역바 시작**을 누릅니다. 처음에는 **다른 앱 위에 표시** 허용이 필요합니다. 허용 후 앱으로 돌아와 시작을 다시 누릅니다.
2. 화면 공유 안내에서 휴대폰 전체 화면 캡처를 허용합니다. 화면 공유 세션은 Android 알림에 표시됩니다.
3. 브라우저나 만화 앱에서 그림 한 장이 잘 보이도록 준비하고 바의 **번역**을 누릅니다.
4. 기존 번역과 바를 잠깐 숨기고 캡처합니다. 바가 다시 보이면 캡처가 끝난 상태이며, 이후 다른 작업을 해도 번역은 계속됩니다.
5. 번역이 끝나면 캡처 당시 원문 위치 위에 한국어를 표시합니다. 화면을 스크롤하거나 옮겼다면 원래 위치로 돌아와야 맞게 겹칩니다.

바의 왼쪽 **⠿**를 끌어 이동합니다. **숨김/표시**는 번역만 감추거나 보여 주고, **지우기**는 현재 표시를 없앱니다. **설정**은 앱 화면을 열고, **×**는 번역바와 화면 캡처 세션을 종료합니다. 번역 중 **중지**를 누르면 결과 표시를 중단합니다.

**원문·번역·처리 결과**에서 일본어 원문, 한국어 번역, 표현 설명, 표시 제외 이유, 사용 모델·추론 수준·처리 시간을 확인합니다. 새 작품으로 넘어갈 때는 **새 작품 · 이전 맥락 초기화**를 누릅니다.

## 불확실한 글자와 효과음

0.1.1부터 **판독이 불확실한 영역은 번역문과 흰 바탕을 모두 표시하지 않고 원문을 남깁니다.** 모델의 불확실 표시와 `[판독 불확실]`, `[판정 불확실]` 문구를 모두 확인합니다. 일부라도 불확실한 문구가 들어 있는 영역은 전체를 숨깁니다. 받은 원문과 번역, 숨긴 이유는 **원문·번역·처리 결과**에서 확인할 수 있습니다.

확실하게 읽힌 효과음은 기본으로 표시합니다. 그림 위 효과음 자체를 줄이고 싶다면 앱의 **번역 표시와 참고사항 → 효과음 표시**를 끕니다. 모델이 효과음으로 분류한 항목을 숨기는 설정이며, 말풍선 밖의 지문까지 모두 제외하는 기능은 아닙니다.

효과음 설정은 자동 저장되고 이미 받은 번역에도 바로 적용됩니다. 표시만 바꾸므로 추가 GPT 요청은 보내지 않습니다. 껐다가 다시 켜도 판독이 불확실한 항목은 계속 숨깁니다.

## 텍스트 배경 투명도

**번역 표시와 참고사항 → 텍스트 배경 투명도** 슬라이더로 0~100% 사이에서 조절합니다. **0%는 가장 진한 흰 배경**, **100%는 흰 배경 없이 글자만 표시**입니다. 기본값은 0%이며 이전 버전의 배경 강도를 유지합니다.

조절하면 자동 저장되고 현재 표시 중인 번역에도 즉시 적용됩니다. 글자 자체를 흐리게 만들거나 번역을 다시 요청하지 않습니다. 원문 글줄을 덮는 부분과 번역문 뒤의 바탕을 함께 조절하며, 겹치는 배경이 더 진해지지 않도록 한 번에 그립니다.

Android의 터치 통과 조건에 따라 오버레이 전체에 적용하는 약한 투명도는 유지합니다. 따라서 0%도 휴대폰 화면에서는 약간 비쳐 보일 수 있습니다.

## 업데이트

기본 배포 저장소는 `Sleeping-Yerre/inventory`입니다. 앱 시작 시 `updates/android.json`을 확인하며 자동 확인은 6시간 간격으로 제한합니다. **업데이트 확인**으로 직접 확인할 수도 있습니다.

새 버전이 있으면 안내하고 **업데이트**를 눌렀을 때 APK를 받습니다. 파일의 SHA-256, 앱 패키지 이름, 증가한 버전 코드, 설치된 앱과 같은 서명인지 확인합니다. Android 설치 허용이 필요하면 직접 설정한 뒤 앱의 **받은 업데이트 설치**를 누릅니다. 최종 설치는 Android 확인 화면에서 사용자가 진행합니다. 확인 없이 몰래 교체하는 방식은 아닙니다.

이 기능에 별도 유료 서버는 필요하지 않습니다. GitHub 공개 저장소의 파일 배포를 사용하며, 앱이 GitHub 계정 비밀키를 요구하거나 보관하지 않습니다.

## 개인정보와 한계

- 번역 버튼을 누른 화면과 번역 참고사항·최근 맥락을 OpenAI에 보냅니다. 캡처 세션 중 보이는 모든 화면을 계속 전송하지 않습니다.
- 계정 연결 정보는 Android Keystore의 AES-GCM 키로 암호화해 앱 전용 저장소에 보관하며 Android 백업에서 제외합니다.
- 캡처 원본과 번역문은 영구 파일로 저장하지 않습니다. 받은 업데이트 APK는 앱의 캐시에 둡니다.
- 서버가 번역을 거절하면 사유를 표시합니다. 번역 지침을 유지해도 서비스의 거절이 사라지는 것은 아닙니다.
- 화면 캡처를 차단한 앱의 화면은 정상적으로 읽지 못할 수 있습니다. 제한을 우회하지 않습니다.
- 원문 위치와 작은 글씨 인식, 장식 효과음, 밀집한 말풍선 배치는 틀릴 수 있습니다. 원문을 확대하거나 글자 크기를 조절해 보세요.
- Android의 터치 통과 조건에 맞춰 번역 레이어는 약간 반투명하게 표시합니다. 원문 일부가 비칠 수 있습니다.
- 화면 움직임·스크롤 추적과 배경 복원은 하지 않습니다. 화면 방향이 바뀌면 현재 번역을 지우고 다시 번역하도록 안내합니다.
- 0.1.2는 Android 17 가상 기기에서 52개 자체 검사를 통과했습니다. 실제 Galaxy S23의 설치·ChatGPT 연결·번역바와 한국어 오버레이 표시 정상 동작은 0.1.0에서 사용자 보고로 확인했습니다. 모든 번역문과 위치의 정확성을 독립 검토한 것은 아닙니다.
