# MangaLens Android 0.1.0 검증 기록

확인일: 2026-11-06. 사용자 대상: Galaxy S23 / One UI 9.0 / Android 17.

## 확인한 결과

- Android SDK Platform 37.0, Build Tools 37.0.0, Java 21로 빌드했다. 최소 SDK 26, 대상 SDK 37이다. 네이티브 라이브러리나 외부 앱 라이브러리를 포함하지 않는다.
- 개인 배포용 3072비트 RSA 키로 APK를 서명했다. `apksigner verify`에서 APK Signature Scheme v2/v3 검증을 통과했다. APK의 패키지 이름은 `app.mangalens.android`이다.
- 별도의 Android 17 x86_64 AOSP ATD 가상 기기에 APK를 실제 설치했다.
- Android 런타임에서 **36개 자체 검사**를 통과했다. 결과: `build/qa/results.txt`.
- Plus 요청의 `store:false` / `stream:true`, 7개 응답 항목, 원래 번역 지침, 선택한 추론 수준의 요청 반영, 지원하지 않는 추론 수준 차단을 확인했다.
- 일본어만 채택, 원문 글줄 합집합의 실제 픽셀 좌표 계산, 좌표 오류 시 받은 번역 보존을 확인했다.
- 완료 스트림의 output item 및 델타 복구, 완료 전 연결 중단 차단, 거절 사유 보존, 사용량 한도에서 별도 API 전환하지 않음을 고정 응답으로 확인했다.
- 실제 RSA 서명·대상·nonce·만료·변조 검사와 중복 OAuth 콜백 차단을 외부 요청 없이 확인했다.
- Android Keystore를 사용한 계정 암호화 저장·복원을 확인했다. 테스트용 계정 정보는 검사 후 지웠다.
- GitHub 저장소 주소 검사, 새 버전 비교, 업데이트 정보 형식, 다른 다운로드 호스트 거부, 잘못된 체크섬 거부, 같은 버전 APK 거부를 확인했다.
- Android 17에서 루프백 소켓 생성·연결이 가능함을 확인했다. 브라우저에서 실제 OpenAI 로그인 콜백을 받았다는 의미는 아니다.
- 한글 단어 중심 줄바꿈과 긴 단어·이모지 결합 문자 보존, Android Canvas의 흰 마스크와 한국어 렌더링을 확인했다.
- 실제 MainActivity를 실행해 로그인·번역바·추론·업데이트 컨트롤과 창 크기를 확인하고 앱의 뷰를 이미지로 렌더링해 검토했다.

## 실기: 사용자 확인

- 사용자가 Galaxy S23 / One UI 9.0 / Android 17에서 공개 배포한 APK를 설치하고 ChatGPT 로그인·요금제 연결까지 완료했다고 보고했다. 제작자가 기기를 직접 조작하거나 연결 로그를 확인한 결과와는 구분한다.
- 이어 실제 일본어 그림을 띄워 번역한 뒤 번역바와 원문 위치의 한국어 표시가 정상이라고 보고했다. S23에서 화면 캡처부터 번역 오버레이 표시까지의 기본 사용 흐름은 사용자 확인으로 기록한다. 번역문 정확성이나 모든 영역의 위치를 제작자가 독립 검토했다는 의미는 아니다.

## 아직 확인하지 않은 항목

- 실제 S23에서의 장시간 사용과 토큰 갱신, 번역 레이어의 터치 통과.
- 원문과 번역의 정확성·누락·좌표·처리 시간에 대한 제작자의 독립 검토. 자동 검사에서는 실제 GPT 요청을 보내지 않았으며, 위 실기 확인은 사용자가 앱에서 실행한 결과다.
- 실기 화면 회전, 잠금·절전·Samsung 배터리 관리, 긴 번역과 밀집한 말풍선의 표시 품질.
- 새 버전 배포 후 실제 Android 설치 화면을 거쳐 업데이트하는 전체 과정. 초기 버전은 같은 서명·버전/체크섬 검사를 자체 검사하고 배포 파일의 무결성을 별도로 확인한다.

## 공개 배포 범위

앱 소스, 번역 지침, 설치용 APK, 사용 안내, 업데이트 정보만 배포한다. PC 또는 휴대폰 로그인 정보, 원본 만화, 실제 번역 결과, 서명 개인키와 비밀번호, 로컬 도구는 포함하지 않는다.
